House Price EDA Project

Exploratory Data Analysis of the Ames Housing Dataset

About the Project

This project explores the Ames Housing Dataset using Python. The goal is to understand house prices, identify important features, handle missing values, detect outliers and discover relationships through data visualization.

Tools & Technologies

  • Python
  • Pandas and NumPy
  • Matplotlib and Seaborn
  • Google Colab

Analysis Performed

  • Data inspection and cleaning
  • Missing value analysis
  • Descriptive statistics
  • Data distributions and visualizations
  • Correlation and covariance analysis
  • Outlier detection
