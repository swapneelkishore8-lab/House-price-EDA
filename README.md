# House-price-EDA
# House Price Prediction – Exploratory Data Analysis (EDA)

## Project Overview
This project focuses on Exploratory Data Analysis (EDA) of the Ames Housing Dataset. The objective is to understand the factors that influence house sale prices using Python and data visualization techniques.

## Dataset
- Dataset: Ames Housing Dataset
- Source: Kaggle – House Prices: Advanced Regression Techniques
- Rows: 1,460
- Columns: 81

## Tools and Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab

## Analysis Performed
- Data loading and inspection
- Missing value analysis and handling
- Numerical and categorical variable analysis
- Descriptive statistics
- Univariate and bivariate analysis
- Correlation and covariance analysis
- Scatter plots and pair plots
- Correlation heatmap
- Outlier detection using IQR and Z-score
- Data quality checks
- Final EDA dashboard

## Key Observations
- SalePrice distribution is right-skewed.
- OverallQual and GrLivArea show strong positive relationships with SalePrice.
- GarageCars and GarageArea are strongly correlated.
- House prices vary across different neighborhoods.
- Missing values and outliers were examined during data cleaning and analysis.

## Project Files
- `House_Price_EDA.ipynb` – Complete Jupyter Notebook containing the analysis.
- `eda_dashboard.png` – Final EDA dashboard.
